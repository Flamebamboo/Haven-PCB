# Haven Kuala Lumpur PCB Badge

So we got sponsored by PCBWay last minute and had only a few hours to design it so it could be shipped on time.
Here's what I made: A simple text book circuit but going details into the design and art. Since a lot of teenagers are not familiar with the use of PCB I decided to turn my art into a tutorial. There's an art for each components that you need for this PCB to work!

## Assembly and use

The design uses a CR2032 holder, a push button, a 3 mm LED and a 1 kΩ resistor. Use the board markings to place the parts and check the LED and battery-holder polarity before inserting the cell. Press the button to light the LED. J2 provides two optional solder points for battery leads.
